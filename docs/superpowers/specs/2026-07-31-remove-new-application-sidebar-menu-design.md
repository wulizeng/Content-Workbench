# 移除“新建申请”侧栏菜单设计

## 目标

从达人端所有左侧导航中移除“新建申请”菜单，避免该功能在侧栏中重复展示。

## 改动范围

- 删除 `index.html` 中“分销枢纽”达人角色菜单里的“新建申请”项。
- 删除 `pages/recruit/mine.html`、`pages/recruit/apply.html` 和 `pages/recruit/project-plan.html` 内嵌侧栏里的“新建申请”项。
- 保留“我的申请”页面内容区的“新建申请”按钮。
- 保留申请页面、现有跳转函数、表单逻辑和权限逻辑。

## 预期行为

用户在任一达人端左侧导航中都看不到“新建申请”。用户仍可从“我的申请”页面的内容区按钮进入新建申请流程，已有申请页面和功能保持不变。

## 验证

- 检索所有侧栏，确认不存在文字为“新建申请”的菜单项。
- 确认“我的申请”页面内容区仍有“新建申请”按钮。
- 确认申请页及其跳转函数未被删除或修改。
