# 达人入驻登记页 PC 端布局重构设计

日期:2026-07-28 · 范围:`pages/recruit/apply.html`(仅 ≥1024px 桌面端;移动端/平板端行为与样式完全不变)

## 问题诊断

1. **形态分裂**:桌面端三张卡片全部铺开(长表单),却配只作锚点用的"步骤导航",既非向导也非规范长表单。
2. **三层同权重**:页首、区块卡、嵌套子卡视觉重量相同,无"页面→区块→字段"层级。
3. **卡中卡**:平台账号子卡嵌套在主卡内且双列排布,视觉噪音大。
4. **导航无信息量**:左侧导航无进度、无各区完成状态。

## 已确认决策(用户选择)

| 决策点 | 选择 |
|---|---|
| 整体结构 | 单页分区 + 左侧目录导航 |
| 平台账号区 | 单行列表式(一行一账号) |
| 提交操作区 | 吸底操作栏(左进度 + 右按钮) |
| 页首 | 加轻量「填写须知/材料清单」概览条 |

## 设计规格

### 四层骨架(≥1024px)

页面框架(概览条 + 主体 + 吸底栏)→ 左目录(250px,sticky top 32px)/ 右主栏(≤860px)→ 编号区块卡 ×3 → 字段行。

- body:flex 布局,`padding: 36px 28px 118px`(底部留出吸底栏高度),背景叠加极浅品牌色径向氛围层。
- 区块卡:白卡、radius 16、shadow-sm、入场 stagger 动画(`--i` 递增延迟)。

### 区块卡头系统(层级核心)

三区块统一卡头:编号徽章 `01/02/03`(未完成灰底描边,完成品牌色实底 + 白字 + 投影)→ 标题 16px 粗 + 13px 一行描述 → 右侧实时状态 chip(`待填写` / `进行中 n/2` / `✓ 已完成`,完成时 pop 动画)。卡头与正文以浅分隔线分区。桌面端隐藏卡头内 svg 图标(编号徽章承担标识)。

区块描述文案:
- 01 基础信息 — 你运营的品牌与主推产品
- 02 平台账号 — 至少填写 1 个运营账号,支持多平台
- 03 业绩证明 — 近 3 个月 GMV 与后台数据截图

### 左侧目录导航

- 顶部:「填写进度」+ `n / 3 区块`(Sora 数字字体)+ 6px 进度条(宽度过渡 .45s)。
- 三项目录:数字圆点 + 名称;状态:✓ 已完成(绿)/ ● 当前(品牌色高亮 + 左侧 3px 指示条)/ ○ 未开始。**全部自由可点**(废除"填完才能跳"的 gating),点击平滑滚动 + 目标卡 flash 提示环。
- IntersectionObserver scrollspy 跟随高亮当前区块。
- 底部:💡 提示卡「提交后 BD 将在 1-3 个工作日内联系」。

### 页首概览条

品牌浅色底横条:⏱「全程约 3 分钟」+ 分隔线 +「请准备」+ 三枚白色 chip(品牌信息 / 平台运营账号 / 后台业绩截图,各带 SVG 图标,hover 微浮起)。

### 吸底操作栏

fixed bottom,毛玻璃白底 + 顶部边线 + 向上阴影;左侧「n / 3 区块已完成」+ 迷你进度条,右侧 取消/提交申请(复用全局 .btn)。提交校验失败:toast + 自动滚动定位到首个未完成区块。只读模式:左侧改为「审核中仅供查看」,右侧仅「返回」。

### 平台账号行

一行 = `[平台 ▾ 180px] [运营账号 flex] [删除]`,带字段标签;行容器浅底圆角,hover 边框转品牌色 + 微阴影;新增行 slideIn 动画;错误行红边框(沿用现有 JS 内联标红逻辑)。

### 字体

新增 Google Font **Sora**(500/600/700)用于编号、进度数字等拉丁数字展示;中文正文沿用系统 PingFang 字体栈。

### 动效与无障碍

- 所有动效 150–450ms,沿用 style.css 缓动变量;`prefers-reduced-motion` 全局降级。
- 字段标签保留可见(不用纯 placeholder);删除按钮保留文字。

### 状态兼容(不改行为)

- 移动端 ≤640px 分步向导、平板 641–1023px 双列:完全不动(仅调整被 DOM 包裹影响的平板选择器:`> .form-card-title` → `> .section-head`,step3 `:first-of-type` → `:nth-of-type(2/3)`)。
- 草稿自动保存/恢复、只读锁定、修改重提、提交数据结构:逻辑不变。
- 设备预览切换器脚本不动。

## 验证
