# 客户入驻申请模板选择设计

## 目标

新建客户入驻申请时先选择业务类型与品牌，再按该组合加载对应的填写字段和后续流程节点。业务类型包含 DP、达播达人、达播机构、客户 KOC、联营 KOC、素人 KOC；品牌使用现有入驻流程定义的巴拉、迷你、森马。

## 交互流程

1. 点击“新建申请”进入申请页的模板选择阶段。
2. 选择业务类型和品牌后，页面即时预览需要填写的材料和后续流程节点。
3. 确认后进入申请编辑阶段，页头固定展示所选业务类型、品牌和模板版本。
4. 未提交时允许重新选择；如已经填写内容，二次确认后清空不适用于新模板的动态字段。
5. 已提交或审核中的申请只读，不允许修改业务类型与品牌；驳回后修改重提时沿用原模板。

## 模板规则

- DP：完整入驻路径，包含资料审核、项目规划、供应商准入、合同网签、保证金、账号录入和红线告知。
- 达播达人、达播机构：使用达人路径，跳过前置入驻资料与项目规划，不需要保证金。
- 客户 KOC、联营 KOC、素人 KOC：使用 KOC 路径，跳过前置入驻资料与项目规划，不需要保证金。
- 六种业务类型分别配置业务专属字段。
- 巴拉、迷你、森马分别追加一个品牌专属必填字段。

## 数据

申请记录新增 `business_type`、`template_key`、`template_version`、`workflow_nodes` 和 `dynamic_fields`。历史记录缺少这些字段时继续可读，按 DP 基础模板兼容展示，不回写历史数据。

## 展示范围

- 申请编辑页动态展示模板摘要、流程节点和业务/品牌专属字段。
- 我的申请卡片展示业务类型与品牌。
- 运营审核列表展示业务类型与品牌，并支持筛选。
- 申请详情展示模板信息、流程节点及动态字段。

## 验证

- 六种业务类型和三个品牌均可生成模板。
- DP、达人、KOC 三类流程节点差异正确。
- 品牌专属字段正确合并，模板对象之间不共享可变数据。
- 新建、草稿恢复、驳回修改重提和只读详情均保留模板信息。
